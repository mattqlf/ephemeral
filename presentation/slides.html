Architecture

Three-stage pipeline

  • Stage 1 — Foundation: Wan 2.1 (14B param image-to-video DiT), text conditioning removed, fine-tuned on visual dynamics
  • Stage 2 — Action modules: injected into first 15 of 30 transformer blocks; trained on ~800h of action-annotated video
  • Stage 3 — Causal distillation: bidirectional → causal streaming via Self-Forcing; 30 denoising steps → 3
Foundation Model

Wan 2.1 backbone

  • 3D Causal VAE: 8× spatial, 4× temporal compression — diffusion operates entirely in latent space
  • DiT: 30-layer transformer with flow matching — learns a velocity field from noise to clean video
  • Text conditioning removed — forces visual/physical understanding over linguistic shortcuts
Action Conditioning

The action module

  • Keyboard: discrete multi-hot vectors injected via cross-attention — movement control
  • Mouse: continuous 2D camera deltas via MLP + temporal self-attention — camera rotation
  • Installed in first 15 of 30 blocks only — halves compute, negligible quality loss
Causal Distillation

From bidirectional to streaming

  • Problem: bidirectional attention — every frame sees the future. Incompatible with streaming.
  • Self-Forcing: student trains on its own outputs, learning to handle its own imperfections
  • Result: 30 denoising steps → 3, with streaming via KV-cache
Causal Distillation

KV-cache & rolling memory

  • Block-wise causal: bidirectional within each 3-frame block, strictly causal across blocks
  • Rolling KV-cache: 6-frame window (~1 second) — oldest frames evicted as new ones arrive
  • Enables indefinite-length generation with bounded memory
Pipeline

From image to interactive world

  • Input: single reference image — CLIP encodes semantic features, 3D VAE compresses to initial latent
  • Each cycle: keyboard + mouse sent via WebSocket; embedded and injected into first 15 DiT blocks
  • Generation: 3 frames in 3 denoising steps; KV-cache updated, oldest frames evicted
  • Output: VAE decodes to RGB, frames to browser — 120ms per block at 25 FPS
